# Pluto
Pluto is a PDP-11/20 Emulator.

## Goal

Boot Unix v2.

## References
1. Processor Manual - https://bitsavers.org/pdf/dec/pdp11/1120/KA11_ProcessorMan_Sep1970.pdf
2. Processor Handbook - https://bitsavers.org/pdf/dec/pdp11/handbooks/PDP-1120_Handbook_1972.pdf
3. Console Manual - https://bitsavers.org/pdf/dec/pdp11/1120/KY11A_ConsoleManual_Sep1970.pdf 

## AI Disclosure

All the code in this project is human written. AI usage is kept very minimal, but not avoided.

Areas where I have used LLMs so far:
- Google search results and conversing with the agent in the AI summary (used mostly for specific details in implementing KA11 Instructions).
- Analyzing my design if I find it too awkward for my taste.
- Generating, Compiling and Running tests for written code.
